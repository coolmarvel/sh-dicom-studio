# 0001 — MVP 마일스톤

브리프의 핵심 시나리오 1~6 을 마일스톤으로 자른다. 기준 명세는 VPWinGate 매뉴얼
(기능 대응은 브리프 참고). 상태 표기: `[ ]` 미착수 · `[~]` 진행 중 · `[x]` 완료 · `[?]` 결정 필요.

## M1 — 창이 뜨고 이미지가 보인다 ✅ 2026-08-06

- [x] Avalonia MVVM 스캐폴드 + 검증 명령(build/format/test) 통과
- [x] 메인 레이아웃: 좌측 도구 패널(자리만) + 우측 썸네일 목록 + 중앙 뷰어 + 상태바
- [x] 파일 열기: JPG/PNG/BMP/TIFF 다중 선택 → 뷰어에 표시 (TIFF 는 Core 에서 PNG 트랜스코드)
- [x] 단일 이미지 뷰: Fit 기본, 휠 Zoom(포인터 중심) / 드래그 Pan / 실제크기 / Reset

## M2 — 뷰어가 VPWinGate 수준이 된다 ✅ 2026-08-06

- [x] 그리드 레이아웃 선택 (1×1~4×4 프리셋) + 페이지 넘김 (First/Prev/Next/Last)
- [x] 이미지 선택(셀 클릭 토글 = 빨간 테두리, Select All 토글) — 도구는 선택된 이미지에 적용
- [x] Image Tools: Rotate ↻/↺·FlipH/V·Invert (픽셀에 직접 적용 — DICOM 변환에 그대로 반영됨)
      ·RealSize·Fit·Reset(선택 셀 또는 전체)
- [x] 순서변경(Cut & Paste — 대상 클릭 후 붙여넣기)·Delete
- [x] 기존 DICOM(.dcm) 열기 (fo-dicom + ImageSharp 렌더링, 멀티프레임은 첫 프레임만)

## M3 — DICOM 으로 변환·저장된다 (성공 기준의 핵심) ✅ 2026-08-06

- [x] 환자·검사 정보 입력 패널: PatientID·이름·성별·생년월일·나이·Modality·StudyDate·
      StudyDesc·AccessionNo·Comment·RefPhysician + Anonymous/AutoClear 옵션 (v0.1.1 에서 선행)
- [x] fo-dicom 으로 Secondary Capture DICOM 생성 (`Core/Dicom/DicomStudy`) — UID 규칙:
      저장 1회 = Study/Series UID 1쌍, 이미지마다 SOP UID·InstanceNumber. UTF-8(ISO_IR 192)
- [x] Save As: 폴더 선택 → `<PatientID>_00001.dcm …` 저장. 선택 없으면 전체, AutoClear 지원
- [x] 라운드트립 검증: 테스트(`DicomStudyTests`) + ShotTool `savetest` E2E (저장→재판독 크기·색 일치)

## M4 — 로컬 DB 로 저장·검색된다 (핵심 완료 2026-08-06)

- [x] SQLite 스키마: Study(환자·검사 메타) / Image(파일 경로·순서) — `Core/Database/LocalDatabase`,
      저장소 `%AppData%/sh-dicom-studio/` (local.db + dicom/<StudyUid>/)
- [x] SaveDB: 현재 화면+정보를 검사 단위로 저장 (DICOM 파일 + 메타 기록)
- [x] FindDB: PatientID·이름·Modality·StudyDate 범위 검색 → 결과 그리드 → 더블클릭/열기(폼
      자동 채움) / 삭제(확인 후 파일까지)
- [ ] InsExam: 저장된 검사에 영상 추가
- [ ] 옵션 화면: 기본 Modality·기본 레이아웃 (설정 파일 저장)
